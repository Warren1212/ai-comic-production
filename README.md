# 漫剧制作 · AI Comic Production

用于 Codex 的通用中文漫剧制作 Skill：从故事与角色设定、分镜、独立首帧，到逐镜口播、视频提示词、画面音频审校和交付。

适用于原创故事、人物叙事、宣传讲述等角色一致性要求较高的AI漫剧。人物、题材、风格、模型和平台均按项目配置，不绑定特定人物或系列。

## 能做什么

- 建立角色参考，稳定脸型、体型、年龄与服装。
- 把四宫格逐格映射为明确镜头与独立首帧。
- 写可直接复制的图片和视频提示词，将上传操作说明单独列出。
- 为每镜或相邻两镜指定具体口播、起止时间与音色。
- 审查人物、手部、车辆、透视和连续性，发现错误后定点返修。
- 每张返回立即保存，支持断点恢复、素材映射、版本归档及交付校验。

支持自动制作和手工上传包两种方式。实际生图、视频和配音需要你自己的可用工具及账户，安装Skill不会附送生成服务或积分。

## 安装

将下面这句话发送给 Codex：

```text
请使用 skill-installer，从 https://github.com/Warren1212/ai-comic-production 安装 skills/ai-comic-production。
```

也可以下载本仓库ZIP，解压后把 `skills/ai-comic-production` 整个文件夹复制到 `~/.codex/skills/`。已有同名技能时先备份，安装后在下一轮对话中使用。

## 使用示例

```text
$ai-comic-production
请根据我提供的故事、人物设定图和声音参考，制作16:9的二维漫剧。
先完成分镜、独立首帧和可手工上传的完整提示词包；暂不提交正式视频。
```

开始时提供源稿、角色设定、风格或构图参考、音色素材，并说明目标画幅、清晰度、模型或平台及授权制作阶段。缺失的信息会先核实；不会从其他项目继承人物身份和剧情。

## 工作流

确认原稿与角色 → 分镜与口播时间线 → 独立首帧 → 逐张审查与返修 → 完整视频提示词 → 已授权的视频生成 → 画面与声音实测审查 → 交付归档。

生成请求成功不等于画面通过；计划配音窗口也不等于实际音画同步。当前项目选择优先，不把历史模型版本或临时尺寸写死。
