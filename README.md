# 漫剧制作 · AI Comic Production

用于 Codex 的通用中文漫剧制作 Skill：从故事与角色设定、单幅或编号拼图分镜、首帧，到单时间轴口播、视频提示词、画面音频审校和精简交付。

适用于原创故事、人物叙事、宣传讲述等角色一致性要求较高的AI漫剧。人物、题材、风格、模型和平台均按项目配置，不绑定特定人物或系列。

## 能做什么

- 建立角色参考，稳定脸型、体型、年龄与服装。
- 按需要制作单幅或三、四、五、六宫格等编号图，每个视频任务只包含自己的分镜，从1开始编号。
- 写可直接复制的图片和视频提示词，将上传操作说明单独列出。
- 每条视频提示词只用一条时间轴，段内说明各分镜时长、具体动作及运镜，完整连续口播放在该段末尾。
- 人物始终使用完整姓名或完整角色称呼，检查正反打、座位、视线和道具的空间连续性。
- 审查人物、手部、车辆、透视和连续性，发现错误后定点返修。
- 每张返回立即保存，支持断点恢复、素材映射、版本归档及交付校验。
- 检查相邻镜头叙事重复；为大幅运镜和场景展开明确首尾构图，必要时制作尾帧。
- 核对停车与行驶间距，区分同场景连续运镜和叠化换景，按动作需要安排收尾时间。
- 将背景音乐要求传递到各任务，返修后同步素材、提示词、衔接、总时长与当前状态；支持轻量文字交接。

## 三种可选生成方式

1. **深度提示词，用户自行生成**：交付自包含的完整提示词和独立的上传顺序、参数说明，用户到自己选择的平台执行。
2. **调用当前模型内置能力**：使用当前环境实际可用的生成工具制作、保存并审查图片；不能把内置生图能力误当视频能力。
3. **调用相关服务的命令行工具**：例如即梦CLI，先核实安装、认证、实际支持的参数和费用，再按用户授权生成、查询并下载结果。

可以为分镜图、视频、配音分别选择方式。首次未选时提供选项；已有选择直接沿用，不反复确认。改变平台、付费路径或制作阶段时按实际授权处理。实际能力与账户额度取决于用户环境，安装Skill不会附送服务或积分。

## 使用示例

```text
$ai-comic-production
请根据我提供的故事、人物设定图和声音参考，制作16:9的二维漫剧。
分镜图请调用当前模型内置能力，按每个视频任务分别生成从1开始编号的拼图。
视频只给我完整深度提示词，由我在平台上操作；暂不提交正式视频。
每镜文件夹放齐实际要上传的图、单时间轴视频提示词和操作说明，不另外打压缩包。
```

开始时提供源稿、角色设定、风格或构图参考、音色素材，并说明目标画幅、清晰度、模型或平台及授权制作阶段。缺失的信息会先核实；不会从其他项目继承人物身份和剧情。

## 工作流

确认原稿、角色及生成方式 → 单时间轴分镜与完整口播 → 单幅/任务专用编号图 → 实看审查与实际返修 → 完整视频提示词 → 已授权的视频生成 → 画面与声音实测审查 → 唯一有效工作目录交付。

每镜就地放齐分镜图、对应提示词和上传说明；历史记录、失败图及旧版放在工作入口之外。用户要求原位修改时直接修改指定版本，不擅自递增版本或创建压缩包。仅提示词路线允许图片尚未生成，但必须如实标注，不能把空目录称作图已完成。

生成请求成功不等于画面通过；计划配音窗口也不等于实际音画同步。当前项目选择优先，不把历史模型版本或临时尺寸写死。
